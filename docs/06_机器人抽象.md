# 设备抽象

## 模块定位

`device` 模块定义机器人、相机和其他外设的统一接口。

运行时只依赖统一设备接口，不依赖具体厂家 SDK。

## 机器人接口

机器人统一接口为 `IRobot`。

接口职责包括：

- 关节运动。
- 直线运动。
- 数字输出。
- 数字输入等待。
- 延时动作。

运行时执行 `Action` 时，根据 `TaskActionType` 调用 `IRobot` 对应方法。

## 相机接口

相机统一接口为 `ICamera`。

相机接口用于获取视觉结果，例如抓取位姿。

视觉动作在任务模型中应表现为普通 `Action`，例如请求相机位姿、等待结果并写入参数。

## 设备实现

具体设备实现放在 `device` 模块下。

示例机器人实现：

```text
include/robot_process_platform/device/robot/hy_robot.h
src/device/robot/hy_robot.cpp
```

设备实现可以是：

- 真实厂家 SDK 适配器。
- 调试用设备实现。
- 仿真设备。

## 运行时边界

运行时只调用设备统一接口。

运行时不关心：

- 机器人品牌。
- 通信协议。
- SDK 类型。
- 相机厂家。
- 外设连接细节。

厂家差异由设备实现或适配层消化。
