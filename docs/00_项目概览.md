# 项目概览

## 项目目标

本项目要实现的是一套通用机器人控制平台，而不是某个单一品牌、单一工艺的专用系统。

平台的核心目标包括：

- 工艺模板与机器人品牌解耦
- 模板负责生成任务，运行时负责执行任务
- 平台统一负责状态、安全、报警、事件和恢复
- 新工艺通过插件扩展
- 新机器人通过适配层扩展

## 当前开发策略

本轮开发采用“先结构、后实现；先文档、后代码；先主干、后细节”的策略。

这样做的原因很明确：

- 当前系统边界复杂，如果直接写代码，后面很容易返工
- 模块边界需要先在目录和文档层统一语言
- 后续要逐模块评审，因此必须保证结构可读、命名清楚、职责稳定
