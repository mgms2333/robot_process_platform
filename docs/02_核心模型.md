# 核心模型

## 职责

核心模型模块负责定义系统中最基础、最稳定的静态数据结构。它不承担执行逻辑，也不包含平台基础设施代码。

这个模块的目标，是为模板、调度器、执行器和适配层提供统一语言。

## 第一批模型范围

本阶段先定义以下最小模型：

- `ActionType`：动作类型枚举
- `Action`：原子动作
- `Step`：工艺语义步骤
- `Task`：完整任务实例
- `TaskConfig`：工艺任务输入配置
- `ProcessPlan`：规划阶段输出的中间工艺计划
- `CreateTaskRequest`：创建任务请求
- `StartTaskRequest`：启动任务请求

## 边界约束

- 核心模型只描述“数据是什么”，不描述“如何执行”
- 不在本模块中引入安全、状态机、事件总线等基础设施概念
- 不直接依赖厂商 SDK 类型
- 字段名以完整语义命名，避免缩写
