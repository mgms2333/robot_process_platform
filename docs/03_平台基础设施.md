# 平台基础设施

## 模块职责

平台基础设施提供与具体工艺无关的通用服务。

这些服务由平台统一管理，模板不应自行实现。

## 平台服务

### DeviceManager

`DeviceManager` 负责设备对象注册和当前活动设备选择。

当前职责包括：

- 注册和注销机器人对象。
- 注册和注销相机对象。
- 查询指定名称设备。
- 设置当前 active robot。
- 设置当前 active camera。

当前 `DeviceManager` 不负责：

- 启动 runtime。
- 推进任务执行。
- 隐式连接设备。
- 替代平台协调层做跨模块编排。

### TemplateManager

`TemplateManager` 负责模板插件生命周期。

职责包括：

- 加载模板动态库。
- 从动态库读取模板名称。
- 创建模板实例。
- 销毁模板实例。
- 卸载指定模板。
- 查询当前已加载模板列表。

模板动态库需要导出统一入口：

- `GetTemplateName`
- `CreateTemplate`
- `DestroyTemplate`

### TaskManager

`TaskManager` 负责根据模板创建和管理任务文件。

职责包括：

- 根据模板名称和输入 JSON 创建 `Task`。
- 为任务生成任务 ID。
- 将生成的 `Task` 保存为本地 JSON 文件。
- 根据任务 ID 读取本地任务文件并恢复为 `Task`。
- 根据任务 ID 删除本地任务文件。

`TaskManager` 不解析具体工艺参数，具体 JSON 内容由模板内部解释。

### Logger

`Logger` 提供平台统一日志能力。

职责包括：

- 输出控制台日志。
- 写入本地日志文件。
- 记录时间戳、日志级别、来源模块和日志内容。
- 支持异步落盘。

### RuntimeService

`RuntimeService` 是当前已经落地的运行时常驻服务骨架。

职责包括：

- 持有运行时线程。
- 接收外部运行时命令。
- 串行处理 `LoadTask / StartTask / PauseTask / ResumeTask / StopTask / EmergencyStop / ResetFault`。
- 持有 `TaskRunner + ExecutionContext`。
- 在 `Running` 状态下周期性调用 `TaskRunner::Tick()`。
- 对外提供 `ExecutionContext` 状态快照。

### 设备准备流程

当前系统已经具备机器人设备对象 `HyRobot`，并支持两种执行形态：

- mock 模式。
- 华沿 SDK 模式。

设备连接不由 `TaskRunner` 或 `RuntimeService` 在执行动作时隐式触发。

连接、断开、切换机器人型号等动作属于平台或设备准备流程，后续应由 `DeviceManager + PlatformService` 一类更高层协调对象统一管理。

## 系统能力边界

以下能力属于平台职责：

- 模板加载与卸载。
- 任务创建、保存、读取和删除。
- 运行时服务线程。
- 运行时状态机。
- 任务执行调度。
- 日志记录。
- 安全联锁。
- 报警生命周期。
- 事件广播。
- 恢复点记录和恢复流程。

以下能力属于具体模板职责：

- 码垛规则。
- 焊接路径策略。
- 上下料流程规划。
- 工艺参数解释。
- 工艺块拆分。
- 从工艺语义展开为 `Task / ExecutionBlock / Action`。

## 平台服务调用关系

```text
Application / Runner
    |
    v
TemplateManager 加载模板
    |
    v
TaskManager 调用模板创建 Task
    |
    v
TaskManager 保存或读取 Task
    |
    v
RuntimeService 驱动 Runtime 执行 Task
```
