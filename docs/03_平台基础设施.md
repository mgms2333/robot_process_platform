# 平台基础设施

本文件将用于定义状态机、安全管理、报警管理、事件总线等平台基础设施模块。

## 哪些属于系统能力

以下能力必须由平台统一提供，而不能下沉到模板内部：

- `TaskManager`：根据模板名称和上下文 JSON 生成任务，并保存或删除本地任务文件
- `TemplateManager`：加载模板 `.so`、卸载指定名称的模板、提供模板实例
- 状态机与运行许可判断
- 安全联锁、急停、安全门、区域检查
- 报警生命周期管理
- 事件总线与系统广播
- 恢复点记录与恢复流程
- 模板注册、模板查找、模板版本兼容检查
- 模板授权检查
- 系统配置与运行时环境上下文提供

## 哪些不属于系统能力

以下内容不应由平台硬编码实现：

- 码垛工艺规则
- 焊接路径策略
- 上下料动作编排
- 工件专属工艺参数解释

这些都应属于具体模板能力。
