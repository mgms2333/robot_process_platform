# 运行时执行链

## 运行时职责

运行时只负责执行已有任务，不负责生成新任务。

因此它的标准输入应当是：

- 已持久化的 `Task`
- 对应的执行上下文

而不是：

- 原始 `TaskConfig`
- 具体模板名

## 运行时组件

后续运行时将包含：

- `StateMachine`
- `StepScheduler`
- `StepQueue`
- `TaskRunner`
- `ExecutionContext`

## 边界约束

- 运行时不负责查找模板
- 运行时不负责生成 `ProcessPlan`
- 运行时不负责 `CreateTask`
- 运行时只负责 `StartTask(task_id)` 之后的执行链
