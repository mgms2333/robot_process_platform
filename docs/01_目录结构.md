## 各目录职责

### 根目录

- `CMakeLists.txt`：项目顶层构建入口
- `README.md`：项目总体说明

### docs

用于承载项目文档，采用编号命名，保证阅读顺序稳定。

### apps

用于放置宿主程序入口，例如最小运行器、调试入口、工具型启动程序。

### include

放对外或跨模块共享的头文件。命名空间目录统一使用 `robot_process_platform`。

### src

放对应模块的实现文件，结构应与 `include/robot_process_platform` 保持一致。

### plugins

放工艺模板插件源码。每个模板插件独立成目录，后续可单独扩展为独立构建单元。
平台主体只放模板抽象，具体工艺模板必须放在这里。

### tests

放测试代码，按单元测试和集成测试分层。

### examples

放示例请求、样例配置、演示输入，不放正式运行时代码。

### config

放系统配置模板和模板配置模板，不混入源码目录。

### scripts

放构建、运行、打包、检查等辅助脚本。

## 命名规则

- 项目总名统一使用 `robot_process_platform`
- 目录名优先使用完整语义，避免随意缩写
- 头文件目录层级要与模块职责一致
- 文档文件采用中文编号命名
- 插件目录名使用工艺英文名，例如 `palletizing`
