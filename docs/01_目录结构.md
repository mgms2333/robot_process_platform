# 目录结构

## 顶层目录

```text
robot_process_platform/
├── apps/
├── build/
├── cmake/
├── config/
├── docs/
├── examples/
├── include/
├── plugins/
├── scripts/
├── src/
├── tests/
├── CMakeLists.txt
└── README.md
```

## 目录职责

- `apps/`：宿主程序入口和调试运行器。
- `cmake/`：CMake 辅助配置。
- `config/`：系统配置和模板配置样例。
- `docs/`：架构、模型、运行时和模板约定文档。
- `examples/`：示例输入和演示材料。
- `include/robot_process_platform/`：平台公共头文件。
- `plugins/`：具体工艺模板插件源码。
- `scripts/`：构建、运行、检查等辅助脚本。
- `src/`：平台主体实现代码。
- `tests/`：测试输入、生成任务、日志和测试代码。

## include 模块

```text
include/robot_process_platform/
├── core/
├── device/
├── platform/
├── plugin/
└── runtime/
```

- `core/`：通用任务模型。
- `device/`：设备抽象接口、机器人配置和设备实现头文件。
- `platform/`：模板管理、任务管理、日志等平台服务头文件。
- `plugin/`：模板接口和模板通用类型。
- `runtime/`：运行时服务、任务执行链、状态机、调度器、队列和执行器。

## src 模块

```text
src/
├── core/
├── device/
├── platform/
├── plugin/
└── runtime/
```

`src/` 与 `include/robot_process_platform/` 保持模块对应关系。

当前 `src/device/robot/hy_robot.cpp` 同时包含：

- mock 执行分支。
- 华沿 SDK 适配分支。

是否编译华沿 SDK 分支由 CMake 选项控制。

## plugins 目录

```text
plugins/
└── palletizing/
    ├── include/
    └── src/
```

`plugins/` 中每个子目录表示一个具体工艺模板。模板通过动态库形式加载到平台，不和平台主体源码混放。

## 命名约定

- 项目命名空间使用 `robot_process_platform`。
- 模块名使用完整语义。
- 头文件路径与命名空间和模块职责保持一致。
- 具体模板目录使用工艺英文名，例如 `palletizing`。
