# 机器人通用工艺控制平台

本项目用于实现一套通用机器人控制平台，目标是将工艺模板、运行时执行链、机器人适配层和平台基础设施拆分清楚，形成可长期演进的后端工程。

当前仓库已经按新的目录结构重置完成，后续会按模块逐步实现，而不是一次性把所有内容堆进去。
